# Encrypted Storage as a Service

Critical path: no. Depends on: none.

## Context

- Wiki: encrypt the data so it matters less who provides storage; IPFS is noted as a building block.
- Autonomi: self-encryption, pay once, stored permanently; every pointer update costs roughly one chunk on chain.
- nostr: Blossom servers and relays store ciphertext, hosted by operators.
- p2panda supports blobs.
- Freenet: data persists only while it is in demand.
- Holochain: Edge Nodes provide always-on peers; no paid hosting market yet.
